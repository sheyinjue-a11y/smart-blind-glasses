# Find-Item 工作流（目标识别 + 引导）

## 目的
该模块检测一个被提示的目标，对其进行锁定，引导其移动到画面中心，然后引导手与目标进行交互。

## 数据流水线
1. 从桥接相机流输入帧。
2. 使用 YOLOE 文本提示进行目标分割。
3. 使用 MediaPipe Hand Landmarker 获取手部关键点。
4. 状态机决策。
5. 将可视化叠加层与引导信息输出到 UI/音频。

## 主要状态

### 1) SEGMENT
目标：在当前帧中找到目标物体掩码。

核心动作：
- 每帧运行 YOLOE 分割。
- 选择一个候选掩码（优先已追踪 id，否则选择面积最大者）。
- 渲染掩码/轮廓反馈。
- 当目标持续可见时启动自动锁定计时器。

状态转移：
- SEGMENT -> FLASH：目标在自动锁定延迟期间持续有效。
- SEGMENT -> SEGMENT：目标缺失或不稳定。

### 2) FLASH
目标：给出锁定确认的视觉反馈，然后初始化光流点。

核心动作：
- 对锁定掩码显示短暂的淡入/淡出高亮。
- 构建内边缘掩码（腐蚀 + 边缘提取）。
- 为 LK 光流提取优质特征点。

状态转移：
- FLASH -> CENTER_GUIDE：提取到足够的特征点。
- FLASH -> SEGMENT：特征点不足。

### 3) CENTER_GUIDE
目标：将目标物体移动到画面中心。

核心动作：
- 使用 LK 光流跟踪多边形。
- 使用 YOLOE 周期性重检，并在漂移较大时重新播种点。
- 计算目标中心到画面中心的方向。
- 输出方向引导与居中成功信号。

状态转移：
- CENTER_GUIDE -> TRACK：目标到达中心并短暂保持稳定。
- CENTER_GUIDE -> SEGMENT：追踪点丢失。

### 4) TRACK
目标：维持目标追踪并引导手靠近目标。

核心动作：
- 持续进行 LK 多边形追踪。
- 运行 YOLOE 校正以抑制漂移。
- 计算手-目标接触比例。
- 生成移动引导（左/右/上/下/前）。
- 执行外围监测，并在需要时重新锁定点。

状态转移：
- TRACK -> SEGMENT：追踪失败或点数不足。
- TRACK -> TRACK：正常引导循环。

## 关键启发式
- 目标选择：优先持久 id；回退到最大掩码面积。
- 锁定点：使用内偏移边缘，避免不稳定的边界点。
- 重新播种触发：YOLOE 掩码与光流多边形之间 IoU 较低。
- 接触检查：手框掩码与目标多边形掩码的重叠比例。
- 引导节流：设置音频间隔以避免提示过于频繁。

## 手动控制
- 在 SEGMENT 按 Enter：强制锁定当前目标并跳转到追踪流水线。
- r：重置到 SEGMENT。
- q 或 Esc：退出。

## 失败恢复
- 任意重大追踪丢失都返回 SEGMENT 进行重新检测。
- 如果 YOLOE 后端不可用，保持 UI 存活并显示降级提示信息。

## 精简状态转移表
- SEGMENT + 目标稳定 -> FLASH
- FLASH + 光流点充足 -> CENTER_GUIDE
- FLASH + 光流点不足 -> SEGMENT
- CENTER_GUIDE + 已居中 -> TRACK
- CENTER_GUIDE + 追踪丢失 -> SEGMENT
- TRACK + 追踪丢失 -> SEGMENT
